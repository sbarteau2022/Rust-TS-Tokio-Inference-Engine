# Context

The new Rust scheduler executes actual Qwen inference through an explicitly approved Rapid/MLX numerical baseline and also supports host-owned integer KV test adapters. The source was reviewed adversarially by its author; this is not independent release approval. Tests and real-model observations are separate evidence classes.

# Decision and resolved attacks

| Attack / failure | Behavior and evidence |
| --- | --- |
| Supply oversized, invalid or partial subprocess receipts | Streaming read rejects beyond 2 MiB; EOF, invalid JSON, timeout and explicit worker errors kill/latch RPC; `tests/rapid_rpc.rs` |
| Use non-ASCII hash characters to panic byte slicing | Require 64 ASCII hex bytes before indexing; adversarial readiness test covers Unicode |
| Return foreign, duplicate, missing or malformed batch members | Validate the entire batch before host commit and close model admission; atomicity and reordered-response tests |
| Return KV under the wrong codec | Immutable frame fingerprint check; malformed lengths, norms and packed tails rejected by codec tests |
| Recycle state when a client cancels a running step | Continue awaiting completion and release acknowledgement; blocked-step cancellation test checks retained charges and eventual zero |
| Exceed memory with retained clones or concurrent producers | Arc lifetime owns the payload charge; CAS reservations reject checked overflow and cap contention; 10,000-cycle and concurrent stress |
| Fail backend state release | Deliver error, latch admission, report failed work; do not emit successful generation |
| Panic during model work | Receiver closes, pending receipt reports unfinished work, admission rejects, and shutdown reports the task error. Review found and corrected telemetry so closed admission is also visible after panic |
| Grow queued work without bound | Fixed admission channel and active-sequence bound; saturation test rejects further work |
| Mix recurrent state between requests | New model cache per sequence, strict position validation and explicit release; real model reports 10 attention / 30 recurrent layers and zero sessions after drain |
| Hide lossy-codec divergence with throughput | A/B logs first resumed-decode logits and full generated tokens; declared diagnostic quality, speed and state-size gates precede ranking |
| Promote synthetic success as model evidence | Synthetic backend identifies itself NONMODEL; real Qwen reports exact artifact/backend hashes and external numerical contract |

# Consequences and open boundaries

1. Rapid's codec compresses prefix storage and expands it before attention. It is not a native packed-attention implementation. The worker executes selected sequences serially within each logical iteration; tensor batching remains open.
2. Rust reservation counters are not physical unified-memory accounting. MLX allocator measurements and cap are separate; driver/OS allocations and transient Python metadata are not controlled by the Rust broker.
3. The external MLX baseline does not enforce the custom Metal runtime's native 2/3-command-buffer cap. Readiness exposes that limitation. Custom integer runtime tests retain their existing native completion guarantees.
4. The fixed-point host codec validates orthogonality tolerance and packing, not random-rotation distribution, optimal codebooks or a full integer Qwen model. No residual-QJL unbiasedness claim is made.
5. Artifact hashing plus metadata checks is not an atomic filesystem snapshot against a privileged concurrent writer. Production needs immutable artifact staging/version fencing.
6. Model quality remains underqualified: a few arithmetic/retrieval prompts and logit comparisons cannot replace held-out datasets, long-context quality sweeps and sustained SLO tests.
7. There is no HTTP/gRPC listener, authentication layer, shared cross-request prefix cache, recurrent-state fork/replay or hot model swap in this milestone. Existing Spec 15 ownership controls are not presented as completed model-state integration.
8. Abrupt process termination remains visible through missing receipts/accounting; it cannot guarantee that all validation or backend work drained. Proposed production sampling modes/rates remain inactive.

# Alternatives considered

Calling an existing HTTP server would provide a quick facade but leave token scheduling and cache ownership inside that server. The private backend worker makes those boundaries explicit for this stage. A full integer rewrite would preserve a uniform numeric contract but requires many missing model operators and calibration; it cannot be inferred from integer microkernels. Stewart explicitly authorized an MLX A/B baseline while that work remains separate.

# Literature grounding

The TurboQuant MSE and inner-product variants are distinct in Zandieh et al., arXiv:2504.19874, https://arxiv.org/html/2504.19874v1. The installed Rapid codec's actual prefix-cache behavior was read in its owning source and is exposed in model readiness. No theoretical guarantee or NVIDIA performance result is borrowed as qualification for this implementation.

# Next steps

Independent domain/QA review, held-out model-quality gates, genuine hybrid tensor batching, packed attention, physical-memory accounting and completion-fenced recurrent/prefix reuse precede production promotion.
